## Resolver policy

- `brand/`、`agents/`、三個 `cases/<case-id>/`、`floorplans/`、`location/` 均為目前可用的展示素材。
- `references/` 與 `product-ui/` 僅作設計比對，狀態為 `OPTIONAL`，不會被報告內容載入。
- 報告 resolver 會優先選用目前可用檔案；若替換包未提供某一類別，使用 CSS/SVG-safe placeholder 並將狀態記為 `MISSING`，不阻斷頁面或 static export。
- 原始素材不覆寫；未來正式素材可依相同相對路徑替換。
