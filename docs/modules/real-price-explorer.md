# Real Price Explorer（實價登錄查詢展示版）

## 模組定位

Real Price Explorer 是提供主管展示與業務銷售輔助的房產市場分析雛形。流程固定為「查詢 → 摘要 → 成交列表 → 圖表 → PDF 報告」，不作為正式實價登錄服務。

## 資料來源策略

- v0.2 使用 `src/data/mock/real-price/real-price-data.ts` 的具型別假資料。
- 資料不來自政府資料、外部 API、爬蟲或真實客戶／案件紀錄。
- 頁面與報告均標示為展示版與 Mock Data；不得將結果用於正式估價、交易或法律／金融判斷。
- Prisma 本輪不新增模型，避免為展示資料引入不必要的資料庫寫入與遷移風險。

## 未來 API 串接方向

正式資料源確認後，新增伺服器端資料來源 adapter，例如 `RealPriceTransactionRepository`。adapter 負責來源憑證、資料正規化、快取、來源時間戳與稽核紀錄；前端只能使用經驗證的查詢結果，不直接持有外部憑證。

## 未來 AI 分析方向

在資料來源、授權範圍與資料品質確認後，才評估區域摘要、可解釋的市場趨勢敘述與異常值提示。本模組目前不提供 AI 房價預測，也不串接任何 AI 服務。

## 報告輸出

第一階段支援本機 PDF 市場摘要，內容包含查詢條件、平均／最高／最低單價、成交筆數與最近成交案例。PNG 匯出與正式列印版型留待後續需求確認。
