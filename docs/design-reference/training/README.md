# E.X Realty Training — Design Reference Pack v2

Design-reference only. Do not import these files into production runtime unless explicitly approved.

## Direction
- Apple-like clarity and craft while keeping E.X Realty identity.
- Light-first, Dark-ready, System-aware.
- Premium SaaS, generous spacing, strong typography.
- Glass hierarchy: light glass for floating controls, medium glass for inspectors/modals, solid high-contrast surfaces for critical information.
- Real-estate warmth + professional trust.
- Avoid neon gaming feel, overly mysterious black surfaces, and Glass-on-Glass-on-Glass.

## Priority
1. Background tone
2. Hero real-estate atmosphere
3. Glass / material language
4. Reusable UI-part language
5. Motion / interaction polish later

Keep under `docs/design-reference/training/`; do not move to `public/` unless a specific asset is approved for real runtime use.
